loadline

Your computer stays responsive while dev servers, builds, installs and coding agents run. Any stack, macOS and Linux, no new commands, nothing turned off.

How it works

You or an agent run

npm ci, bin/rails server, cargo build, pytest, go run… exactly as today.

→

1 · Fewer workers

Each tool is told about half your cores: Node preload plus caps for Cargo, Go, Turbopack, Python, pytest, Bundler, Rails, .NET.

→

2 · Tiny helper

A few heavy jobs at a time, the rest wait their turn. Idle servers sleep and wake on the next request. Pauses the newest build when memory is critical.

Safety

Never kills

Only pauses, resumes and lowers priority. Your processes only, no root, no network.

Never breaks your terminal

Never pauses what a shell waits on; prints one line when a job has to wait.

Crash-safe and reversible

Writes down what it pauses first; loadline off resumes all; uninstall removes every line it added.
